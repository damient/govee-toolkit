# Inizia qui

Questa pagina spiega cosa serve a una luce Govee perché il tuo computer possa
raggiungerla. Ogni passaggio è un'impostazione o un comando.

## Cosa ti serve {#what-you-need}

1. Una luce Govee.
2. Un computer sulla stessa rete Wi-Fi della luce.
3. L'app Govee Home sul telefono, una sola volta, per attivare un interruttore.

## Attiva LAN Control {#turn-on-lan-control}

{{badge_lan}} — apri l'app Govee Home, seleziona il tuo dispositivo, apri le sue
impostazioni, poi attiva **LAN Control**. Questo interruttore permette alla tua
rete di raggiungere il dispositivo. Senza, niente di questo sito funziona via Wi-Fi.

Non tutti i modelli hanno l'interruttore.
[La pagina dei dispositivi]({{base}}devices/) elenca ogni modello presente
nell'elenco di Govee dei modelli che lo hanno, e dice cosa è verificato qui.

## API per il cloud (facoltativa) {#api-for-cloud-optional}

{{badge_cloud}} — questa modalità passa dall'API di Govee, quindi le servono una
chiave API e il dispositivo registrato su quell'account. Richiedi la chiave
nell'app Govee Home: profilo, poi impostazioni, poi **Apply for API key**.
