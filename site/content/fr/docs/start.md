# Commencer ici

Cette page décrit ce dont une lumière Govee a besoin pour que votre propre
ordinateur puisse la joindre. Chaque étape est un réglage ou une commande.

## Ce qu'il vous faut {#what-you-need}

1. Une lumière Govee.
2. Un ordinateur sur le même réseau Wi-Fi que la lumière.
3. L'application Govee Home sur votre téléphone, une seule fois, pour activer un interrupteur.

## Activer LAN Control {#turn-on-lan-control}

{{badge_lan}} — ouvrez l'application Govee Home, sélectionnez votre appareil, ouvrez ses
réglages, puis activez **LAN Control**. Cet interrupteur permet à votre propre réseau de
joindre l'appareil. Sans lui, rien sur ce site ne fonctionne en Wi-Fi.

Tous les modèles n'ont pas cet interrupteur.
[La page des appareils]({{base}}devices/) recense chaque modèle de la liste
Govee des modèles qui le possèdent, et indique ce qui est vérifié ici.

## API pour le cloud (facultatif) {#api-for-cloud-optional}

{{badge_cloud}} — ce mode passe par l'API de Govee : il lui faut donc une clé d'API
et l'appareil enregistré sur ce compte. Demandez la clé dans l'application Govee Home :
profil, puis réglages, puis **Apply for API key**.
