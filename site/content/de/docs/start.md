# Erste Schritte

Diese Seite beschreibt, was eine Govee-Leuchte braucht, bevor dein eigener
Computer sie erreicht. Jeder Schritt ist eine Einstellung oder ein Befehl.

## Was du brauchst {#what-you-need}

1. Eine Govee-Leuchte.
2. Einen Computer im selben WLAN wie die Leuchte.
3. Die Govee Home App auf deinem Handy, einmal, um einen Schalter einzuschalten.

## LAN Control einschalten {#turn-on-lan-control}

{{badge_lan}} — öffne die Govee Home App, wähle dein Gerät, öffne seine
Einstellungen und schalte **LAN Control** ein. Mit diesem Schalter erreicht dein
eigenes Netzwerk das Gerät. Ohne ihn funktioniert nichts auf dieser Seite über
WLAN.

Nicht jedes Modell hat den Schalter.
[Die Geräteseite]({{base}}devices/) führt jedes Modell aus Govees eigener Liste
der Modelle auf, die ihn haben, und sagt, was hier verifiziert ist.

## API für die Cloud (optional) {#api-for-cloud-optional}

{{badge_cloud}} — dieser Modus läuft über die API von Govee. Er braucht deshalb
einen API-Schlüssel und das Gerät, registriert auf dieses Konto. Beantrage den
Schlüssel in der Govee Home App: Profil, dann Einstellungen, dann
**Apply for API key**.
