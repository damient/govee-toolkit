# Empieza aquí

Esta página cubre lo que necesita una luz Govee antes de que tu propio
ordenador pueda alcanzarla. Cada paso es un ajuste o un solo comando.

## Qué necesitas {#what-you-need}

1. Una luz Govee.
2. Un ordenador en la misma red Wi-Fi que la luz.
3. La app Govee Home en tu teléfono, una sola vez, para activar un interruptor.

## Activa LAN Control {#turn-on-lan-control}

{{badge_lan}} — abre la app Govee Home, selecciona tu dispositivo, abre sus
ajustes y activa **LAN Control**. Este interruptor permite que tu propia red
llegue al dispositivo. Sin él, nada de este sitio funciona por Wi-Fi.

No todos los modelos tienen el interruptor.
[La página de dispositivos]({{base}}devices/) lista todos los modelos de la
propia lista de Govee que lo tienen, e indica qué está verificado aquí.

## API para la nube (opcional) {#api-for-cloud-optional}

{{badge_cloud}} — este modo pasa por la propia API de Govee, así que necesita
una clave de API y el dispositivo registrado en esa cuenta. Pide la clave en la
app Govee Home: perfil, después ajustes, después **Apply for API key**.
