# Home Assistant integration

Python custom component, distributable through HACS, consuming
`packages/python`.

Worth having alongside the [Matter bridge](../matter/): it is the integration
that can carry the undocumented LAN scenes and segments, which the Matter data
model cannot express.

Scope for the first pass: turn on/off and brightness over LAN. Everything else
comes after.

Start only once `packages/python` is stable.
