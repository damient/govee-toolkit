# govee-toolkit (Node.js)

Node.js / TypeScript SDK. `lan` mode by default; `ble` and `cloud` modes are
opt-in, enabled per device by the user — see
[`../../docs/modes.md`](../../docs/modes.md). Also used by
`apps/playground`, `apps/desktop`, `packages/artnet-dmx-bridge` and
`integrations/homebridge`.

Reads the shared device database in [`../../devices/`](../../devices/).
